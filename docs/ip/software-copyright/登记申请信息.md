## 2. 软件用途（申请表"软件用途"栏，建议 300 字以内）

本软件面向流程工业（化工、冶金、电力等）的先进过程控制与建模工程师，解决工业历史数据
中"有效辨识样本被海量稳态数据淹没"的问题。系统以自然语言为入口，由 Agent 编排受白名单
约束的算法工作流，对多变量时序数据依次完成时间规整与清洗、动态区间检测、质量约束下的
D-最优数据优选、时滞估计与补偿、共线性诊断与降维、ARX 系统辨识、双口径模型评价
（一步预测 + 自由仿真）与闭环寻优，最终交付可复现的数据版本、模型参数、评价指标与
全数值可溯源的图文报告。系统支持本地离线部署，不依赖外部网络与商业数学软件。

## 3. 技术特点（申请表"技术特点"栏，建议 300 字以内）

1. **以信息量而非经验权重决定选段**：将回归窗口对 Fisher 信息矩阵的贡献作为选择依据，
   目标函数为 `log det(λI + ΣΦᵀΦ)`，用矩阵行列式引理计算增量增益并以惰性贪心加速；
2. **质量门控前置于信息准则**：缺失、异常、稳态、信噪比先行筛除，避免高信息量的污染段被选入；
3. **以自由仿真 FIT 为模型主指标与闭环目标函数**，一步预测 FIT 降级为诊断量，二者差值作为过拟合信号；
4. **数据血缘即缓存**：以父版本、工具名、工具版本、规范化参数与代码版本的哈希作为内容寻址键，
   闭环寻优中重复的预处理阶段直接复用；
5. **报告数值全程可溯源**：报告生成环节禁止语言模型输出数字字面量，只允许输出占位符，
   由渲染器绑定到实际运行记录，草稿含未绑定数字即被拒绝；
6. **Agent 计划受静态合规校验**：工具白名单、执行图无环、时序合法、高影响操作须经确认，
   校验产生可机器复核的签名证明。
