## 一、问题

赛题原文点出的痛点是：**"真正富含动态价值的有效辨识样本被海量稳态数据淹没。"**

工厂历史库里躺着几年的数据，但装置绝大多数时间运行在稳态——输入不动，输出也不动。
这类样本增加行数却不增加信息。真正能确定模型参数的，是那些短暂的动态片段：
一次阀位调整、一次负荷升降、一次工况切换。

现有做法有两类，各有其失效方式：

- **人工圈选**：靠工程师翻趋势图，慢、不可复现、结果因人而异；
- **加权质量评分**：对滑动窗口算能量、信噪比、响应关联度等特征，加权求和取前 K 段。

第二类是本赛题多数实现会采用的路线——**任务清单本身就写着这套特征**。

---

## 二、我们发现的问题

我们把这套加权评分按规范原样实现，作为对照基线跑了 10 组种子。结果是：

**在激励不均匀的数据上，加权评分与"只看输入变化能量"没有区别**——参数相对误差
14.81% 对 14.82%，两者都秩亏。

问题不在于特征选得不够全，而在于**逐窗口独立打分这个形式本身**：
评分公式里没有任何一项能表达"这个窗口和已经选中的窗口在讲同一件事"。

而激励不均匀恰恰是真实历史数据的常态——操作员在不同时期调整不同的阀，
显眼的大动作集中在少数变量上。按分数排序，预算会全部花在幅度最大的那个变量上，
其余变量在选中样本里近似恒定，它们的增益被估计成接近零。

---

## 三、我们的做法

**不问"这段数据质量多好"，问"这段数据能给模型带来多少新信息"。**

把候选片段对 Fisher 信息矩阵的贡献作为选择依据，目标是最大化
`log det(λI + Σ ΦᵀΦ)`。这个准则天然表达信息冗余：一个与已选片段重复的窗口，
增量增益接近零。

围绕它构建的完整闭环：

```
工业 CSV 上传 → 时间规整与清洗 → 动态区间检测 + 质量门控
→ 质量约束 D-最优数据优选 → 时滞估计与补偿 → 共线性诊断与降维
→ ARX 系统辨识 → 双口径模型评价 → 闭环寻优 → 历史策略热启动
→ Agent 自然语言编排 → 一键自评测基准 → 溯源图文报告 → 优选数据集导出
```

一句自然语言即可驱动全流程。

## 四、四个差异化设计

### 1. 门控先于信息准则

含尖峰或大段缺失的窗口"信息量"往往极高。如果直接用信息准则选段，污染会被优先选入。
所以质量门控前置：不合格的窗口在参与信息量比较之前就被剔除，且每一条拒绝理由都被记录。

### 2. 主指标是自由仿真 FIT，不是一步预测 FIT

工业过程输出强自相关，模型只要"抄上一时刻"就能拿到很高的一步预测分数。
实测：一个参数误差 15%、稳态增益完全错误、设计矩阵秩亏的模型，一步预测 FIT 仍有 96.5,
只比最优模型低 0.5 分；同组模型的自由仿真 FIT 跨度是 15.3 分——**区分度差 28.5 倍**。

赛题字面要求用一步预测 FIT 做闭环目标函数。我们没有照做，并给出了不照做的实测理由。
一步预测 FIT 保留为诊断量：它与自由仿真的差值就是过拟合信号。

### 3. 报告里的数字，大模型一个都不许写

大模型负责撰写文字结论，但只能输出占位符，由渲染器绑定到真实运行记录。
含未绑定数字的草稿会被拒绝并要求重写，连续三次不合规则回退到模板化结论。

同理，大模型生成的执行计划必须通过与规则计划**完全相同**的白名单、执行图与合规校验，
`requires_confirmation` 一律取自白名单而非模型输出。

**大模型负责提议，不负责授权。** 模型不可用、输出畸形甚至刻意越权，
最坏结果都只是"回退 + 说明"。

### 4. 系统能当场检验自己的主张

产品内置「一键自评测基准」：点一次按钮，系统用带真值的仿真基准实时重算全部技术主张。
**没有任何数字是缓存的或写死的**——主张一旦不成立，表格会立刻显示出来。

## 五、实测结果（含不利结果）

| 结论 | 来源 |
|---|---|
| D-最优用 **14.3% 的数据**达到全量数据的辨识精度（参数误差 4.54% vs 4.61%），条件数更优 | `EXP-2.1` S6 |
| 同等预算下能量启发式与完整加权分**同时失效**：误差 15%、增益估成零、设计矩阵秩亏 | `EXP-2.1` S6 |
| 结论不是单点巧合：**200 个工作点**上 D-最优参数误差最优 18/20、满秩 16/20 | `EXP-3.0` |
| 一步预测 FIT 区分度仅为自由仿真 FIT 的 **1/28.5** | `EXP-2.1` S6 |
| 闭环分级搜索使昂贵环节摊薄 **24 倍** | 阶段 8 实测 |

**我们同时提交对自己不利的结果：**

| 不利结论 | 我们的态度 |
|---|---|
| 同构激励下 D-最优**排在末位**（4.80%，落后加权分 3.75%、全量 3.76%） | 价值在于"不会崩"，不是"永远最优"。差距约 1 个百分点；异构激励下的差距是 11 个百分点加秩亏 |
| 预算太小时（预算/窗长 ≤ 2.3）D-最优**同样秩亏** | 这不是准则失灵，是预算不足。已作为提示写进产品，不让工程师在不知情时拿到秩亏模型 |
| 内容寻址缓存命中率仅 **1.7%** | 真正的节省来自分级搜索。据实上报，不把收益错误归因 |
| 预白化时滞估计 **4 胜 1 负 1 平** | 占优但非全胜，报告里就这么写 |
