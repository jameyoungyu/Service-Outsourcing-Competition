# 阶段 2：仿真数据与 ARX 基线实现记录

版本：`ALG-2.0`  
状态：已完成后端验收，等待前端真实接口绑定与阶段 3 数据集管理。

## 实现范围

- `backend/app/services/simulation_service.py` 生成 S1–S5，并将 CSV、真值 JSON 与版本清单写入 `backend/data/simulation/`。
- `backend/app/services/identification_service.py` 从不可变版本 CSV 读取数据，构建 MISO ARX 回归矩阵，执行 OLS 或 Ridge，并在 `backend/data/models/` 持久化模型结果。
- 真值只用于离线参数误差评测；ARX 拟合过程不读取真值 JSON。

## 场景与真值

| 场景 | 生成特性 | 主要用途 |
|---|---|---|
| S1 | 单输入、`na=2`、`nb=2`、`nk=3`、低噪声 | 参数映射、OLS/Ridge 和一步预测正确性 |
| S2 | 2–4 个输入、默认延迟 `3/8/5/11` | 多输入不同延迟的后续时滞估计 |
| S3 | 约 80% 稳态、阶跃/斜坡/脉冲动态段 | 动态区间筛选的真值基准 |
| S4 | 缺失、尖峰、冻结、漂移、不规则及重复时间戳、强噪声 | 阶段 3–4 诊断与清洗对照 |
| S5 | `u2 = 0.97*u1 + ε`，相关性通常大于 0.95 | 共线性与变量筛选基准 |

每份真值 JSON 包含 ARX 参数、按输入变量记录的延迟、动态段、缺失/尖峰索引、冻结/漂移段、时间戳污染索引、冗余变量、依赖关系、噪声与随机种子。

## ARX 约定

实现的模型为：

```text
y(t) + Σ a_i y(t-i) = Σ_j Σ_l b[j,l] u_j(t-nk_j-l) + e(t)
```

特征顺序固定为 `a1..a_na`（特征为 `-y(t-i)`），然后按请求的输入列顺序放置 `b_<input>_0..b_<input>_(nb-1)`。OLS 使用稳定的 `numpy.linalg.lstsq`，Ridge 求解 `(XᵀX + αI)θ = Xᵀy`。OLS 在秩不足时返回 `DESIGN_MATRIX_RANK_DEFICIENT`，不会静默给出不可靠参数。

时间序列先按原始索引切为 60%/20%/20%，分区边界各移除 `max(na, nk + nb - 1)` 的保护区。训练仅用于参数估计；验证和测试仅用于评价。返回 RMSE、MAE、R²、NRMSE、FIT、真实/预测序列、残差和残差 ACF。

## 固定种子基线

以下结果均由当前代码、3,000 个样本、固定种子运行；S4 未经清洗，低性能是保留给后续阶段的必要对照。

| 场景 | Seed | 求解器 | 参数相对误差中位数 | 测试 RMSE | 测试 R² | 测试 FIT |
|---|---:|---|---:|---:|---:|---:|
| S1 | 4201 | OLS | 0.096% | 0.0104 | 0.999994 | 99.76% |
| S2 | 4202 | OLS | 0.796% | 0.0304 | 0.999960 | 99.36% |
| S3 | 4203 | OLS | 14.710% | 0.0310 | 0.999544 | 97.86% |
| S4 | 4204 | Ridge (`α=0.1`) | 366.055% | 8.2473 | -0.175372 | -8.41% |
| S5 | 4205 | Ridge (`α=0.1`) | 0.927% | 0.0203 | 0.999980 | 99.55% |

S1 无噪声的自动化测试要求四个参数的最大相对误差小于 1%，并同时验证测试 FIT 大于 99.99%。S3 的参数误差受有限动态信息影响，仍保留真实低稳态比例，不能为了基线表现人为改变为持续激励数据。

## API 兼容性

仿真接口同时接受后端字段 `name/n_steps/noise_sigma` 和现有前端字段 `dataset_name/num_samples/noise_level`，后者优先。ARX 同时接受按变量名的 `nb/delays` 字典及前端使用的同序数组，`estimation_method` 可作为 `estimator` 的兼容别名。

响应保留阶段 1 字段，并补充前端所需的 `dataset_name`、受控相对产物标识、真值完整字段、`a_coefficients`、`b_coefficients`、`metrics.rmse` 与 `plot_data.split_indices`。这些均为新增字段；未删除已有路由或成功/错误信封。
