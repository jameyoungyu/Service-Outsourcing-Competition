# IndusOpt 工模智优 - 低保真页面草图 (Low-Fidelity Wireframes)

**文档版本**：`v0.1.0`  
**适用阶段**：阶段 0（需求与设计冻结）  
**责任角色**：Gemini (前端与可视化架构师)  

---

## 1. 页面草图设计原则

IndusOpt 的 UI 布局秉承**“专业工业仪表盘 (Professional Industrial Workspace)”**理念：
* **结构清晰**：固定顶栏与左侧导航，主内容区采用模块化 Card/Panel 风格。
* **注重可对比性与证据链**：算法处理前后对比、实际 vs 预测对比、基线 vs 最优对比均为并排/叠加设计。
* **上下文感知**：右侧对话侧边栏可在任意页面一键呼出，实时感知当前激活的数据集与路由状态。
