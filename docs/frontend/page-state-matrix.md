# IndusOpt 工模智优 - 前端页面异步状态矩阵 (Page State Matrix)

**文档版本**：`v0.1.0`  
**适用阶段**：阶段 0（需求与设计冻结）  
**责任角色**：Gemini (前端与可视化架构师)  

---

## 1. 状态矩阵规范说明

在 Industrial/Agent 协同交互中，绝大部分数据处理与系统辨识操作均属于**异步长耗时流程**。为了防止用户发生“界面假死”、“误认为算法出错”或“无法恢复数据”的体验缺失，前端所有与后端 API 交互的 View 和 Component 必须覆盖以下 12 种状态标准。

---

## 2. 异步状态矩阵表

| 状态 ID | 状态名称 | 前端视觉与 UI 表现 | 必须呈现的信息 | 允许的操作与恢复入口 |
|---|---|---|---|---|
| **ST-01** | **初始空状态 (Initial Empty)** | 干净的工业占位区，置灰占位图形，明晰的提示文字 | “尚未选择/生成数据集”、“推荐行动说明” | `[ + 生成仿真数据集 ]`<br>`[ ↑ 上传 CSV 文件 ]` |
| **ST-02** | **文件上传中 (Uploading)** | 模态框/文件拖拽框展示进度条与动画 | 文件名、文件大小、当前传输速率、传输百分比 | `[ ✖ 取消上传 ]` |
| **ST-03** | **后端解析中 (Parsing)** | 局部骨架屏 (Skeleton) + 柔和 Spinner | 当前解析阶段（如：编码识别中 -> 时间戳对齐中 -> 校验数据行） | 禁用表单，显示预计剩余耗时（如：约 2-5 秒） |
| **ST-04** | **配置错误 (Config Error)** | 黄/红色警告 Banner 弹出在字段映射面板顶部 | 报错字段名、行号（如：“列 'timestamp' 第 142 行包含无效时间格式 'N/A'”） | `[ 🛠 更改时间格式 ]`<br>`[ ✖ 忽略该行并继续 ]` |
| **ST-05** | **排队中 (Queued)** | 任务状态 Badge 显示黄色 `[ Queued ]` | 队列位置（如：“前面尚有 1 个任务等待中”）、任务创建时间 | `[ ✖ 撤销排队 ]` |
| **ST-06** | **算法运行中 (Running)** | 顶部全局指示器 + 页面局部进度条 + 交互面板遮罩 | 当前步骤工具名（如 `hampel_filter`）、耗时 `12.4s`、当前 Trial 进度 | `[ ⏹ 中途停止算法 ]` |
| **ST-07** | **部分成功 (Partial Success)** | 黄绿色提示 Banner | “已完成清洗与动态截取，但共线性剔除步骤被忽略” | `[ 查看已完成部分 ]`<br>`[ 补全未完成步骤 ]` |
| **ST-08** | **等待人工确认 (HITL Wait)** | 带有闪烁提示音/高亮边框的 Agent 决策卡片 | 变更原因、预计丢弃数据比例、预测 FIT 提升幅度、数据对比证据 | `[ ✔ 同意并执行 ]`<br>`[ ✖ 拒绝(使用保守参数) ]`<br>`[ ✍ 手动修改参数 ]` |
| **ST-09** | **执行成功 (Success)** | 绿色 Checkmark 提示 + 结果对比面板 | 新数据版本号（如 `V2_Cleaned`）、核心指标提升幅度、算法耗时 | `[ 查看派生版本 ]`<br>`[ 导出 CSV ]`<br>`[ 进入下一步 -> ]` |
| **ST-10** | **执行失败 (Failure)** | 红色 Error 面板 + 详细可读错误诊断卡片 | 错误码（如 `ERR_SINGULAR_MATRIX`）、原因解释（共线性过高）、算法 Traceback | `[ 🔄 一键重试 ]`<br>`[ ⏪ 撤销回退到 V1 ]`<br>`[ 查看详细日志 ]` |
| **ST-11** | **已手动取消 (Cancelled)** | 灰色 Badge `[ Task Cancelled ]` | 已保存的阶段性中间产物列表、取消发生的时间点 | `[ 保留当前产物 ]`<br>`[ 清理并重新开始 ]` |
| **ST-12** | **数据过多下采样 (Over-Sized)** | 蓝灰色提示 Tooltip 附在图表右上角 | 实际数据量（例：1,200,000 行）、当前前端渲染下采样步长 | `[ 🔍 框选局部显示原始精度 ]`<br>`[ 导出全量原始数据 ]` |

## 3. 典型页面状态切换状态机 (State Machine)

```text
               +-------------------------------------------------------+
               |                                                       v
[ ST-01 空状态 ] ---> [ ST-02 上传中 ] ---> [ ST-03 解析中 ] ---> [ ST-04 配置错误 (可修复) ]
                                                |
                                                v
[ ST-10 执行失败 ] <--- [ ST-06 运行中 ] <--- [ ST-05 排队中 ]
       |                      |                  |
       |                      +------------------+-----> [ ST-11 已手动取消 ]
       v                      |
[ ⏪ 撤销回退 ]               +-----> [ ST-08 人工确认 (HITL) ]
                                                 | (确认后)
                                                 v
                                       [ ST-09 成功 / ST-12 下采样 ]
```
