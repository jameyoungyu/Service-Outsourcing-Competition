## 1. 站点导航与模块结构

IndusOpt 采用典型的**高信息密度工业软件布局**：左侧为系统主导航菜单（可收起），顶部为状态栏与全局上下文（包含当前激活的数据集与工作区），中间为主内容区，右侧可展开 Agent 辅助侧边栏。

```text
+-----------------------------------------------------------------------------------+
| [Logo] IndusOpt 工模智优 | [当前数据集: S3_Simulation_v1]  | [全局任务: 寻优中 45%] | [设置] |
+---------------+-------------------------------------------------------------------+
|  主导航       | 主工作区域 (Main Content Area)                                    |
|               |                                                                   |
|  - 工作台     |  [ 选项卡 / 页面视图 ]                                             |
|  - 数据资产   |  +-------------------------------------------------------------+  |
|  - 仿真生成   |  |                                                             |  |
|  - 清洗与规整 |  |                                                             |  |
|  - 动态优选   |  |                                                             |  |
|  - 时滞分析   |  |                                                             |  |
|  - 共线性剔除 |  +-------------------------------------------------------------+  |
|  - 系统辨识   |                                                                   |
|  - 闭环寻优   |-------------------------------------------------------------------|
|  - Agent工作台| Agent 对话与协同抽屉 (Drawer / Split Panel)                       |
|  - 报告与交付 | [输入: 帮我提取高信噪比段并寻找最优 delay ...] [发送]               |
+---------------+-------------------------------------------------------------------+
```

## 2. 页面树与路由映射

```text
/ (Layout: DefaultLayout)
├── /dashboard                      [工作台]
│   └── 概览指标、快捷入口、运行中的 Task、最近模型排行榜
│
├── /simulation                     [仿真生成]
│   └── S1-S5 场景生成表单、仿真参数配置、生成历史、真值卡片对比
│
├── /datasets                       [数据资产]
│   ├── / (List)                    ── 数据集表格、上传入口、总体统计
│   └── /:dataset_id (Detail Hub)   ── 数据集详情页（含 Tab 标签页）：
│       ├── #overview               ── 基础数据表头、变量定义与列映射
│       ├── #profile                ── 质量诊断报告（缺失率、采样率、极值）
│       ├── #versions               ── 数据版本血缘图 (DAG) 与回溯记录
│       └── #artifacts              ── 派生 CSV/模型导出产物
│
├── /preprocessing                  [数据优选与预处理]
│   ├── /cleaning                   ── 重采样、插值、异常值检测 (IQR/Hampel) 前后对比
│   ├── /segmentation               ── 无标签动态响应区间筛选、SNR/动态度评分与高亮
│   ├── /delay                      ── 多输入滞后 correlation 分析、候选 Peak 与时滞补偿
│   └── /collinearity               ── Pearson 热图、VIF 矩阵、变量剔除与合并建议
│
├── /modeling                       [系统辨识与闭环]
│   ├── /arx                        ── ARX 模型结构配置 (na, nb, delay)、OLS/Ridge 拟合、残差 ACF
│   ├── /comparison                 ── 基线 vs 优选数据模型拟合度对比
│   └── /optimization               ── Optuna 闭环自动寻优、Trial 收敛图、超参重要性
│
├── /copilot                        [Agent 智能工作台]
│   └── 自然语言对话界面、结构化 Execution DAG、工具调用 Logs、人工 Task 确认卡片
│
├── /deliverables                   [交付与审计]
│   ├── /reports                    ── 自动生成的 PDF/Markdown 建模分析报告预览
│   ├── /exports                    ── 优选数据集 CSV 下载与 API 导出格式
│   └── /runs                       ── 算法处理 Run 记录与审计日志
│
└── /settings                       [系统配置]
    └── LLM Token 设置、后端 API 健康检查、存储与清理策略
```

## 3. 核心页面功能职责明细

### 3.1 概览工作台 (`/dashboard`)
* **核心指标卡**：当前活跃数据集、历史最高 $R^2$/FIT 成绩、已执行闭环 Trial 总数。
* **快捷行动组**：`[一键生成仿真数据]`、`[上传 CSV]`、`[启动 Agent 自动化流程]`。
* **最新闭环排行榜**：展示不同预处理组合对最终 ARX 辨识 FIT 指标提升效果的 Leaderboard。

### 3.2 仿真生成 View (`/simulation`)
* **预设场景选择**：S1 基础单输入、S2 多输入不同滞后、S3 长稳态短动态、S4 强噪声与污染数据、S5 高共线性。
* **参数调控面板**：采样步数、噪声标准差 $\sigma$、异常值比例、随机种子 `seed`。
* **真值卡片 (Ground Truth Card)**：显示真值模型参数 $a_i, b_j$、真实时滞 $\tau_{true}$、真实动态区间范围，供后序算法对比验证。

### 3.3 数据集详情 Hub (`/datasets/:dataset_id`)
* 采用统一的标签页结构整合数据资产：
  * **概览 Tab**：数据前 100 行预览、时序多变量总览折线图。
  * **质量诊断 Tab**：缺失率柱状图、采样间隔直方图、常量列与冻结段警告卡片。
  * **版本血缘 Tab**：可视化展示 `V0 -> V1(Cleaning) -> V2(Segment) -> V3(Delay)` 的版本关系图。

### 3.4 动态区间优选 View (`/preprocessing/segmentation`)
* **多变量时序主图**：背景使用半透明彩色矩形标注识别出的高动态响应区间（Segment 1, 2, 3...）。
* **区间评分列表**：按动态指标（变化率、方差）与信噪比 SNR 综合打分排序。
* **筛选控制台**：允许用户设置“最小区间长度”、“最低 SNR 阈值”或“只保留 Top K 动态段”。

### 3.5 时滞分析 View (`/preprocessing/delay`)
* **Lag Correlation 曲线图**：绘制不同输入变量 $u_m(t-\tau)$ 与输出 $y(t)$ 在不同滞后步数 $\tau \in [0, \tau_{max}]$ 下的相关系数。
* **候选 Peak 表格**：列出检测到的峰值滞后步数与显著性评分。
* **补偿操作**：提供 `[应用时滞补偿并生成新数据版本]` 按钮。

### 3.6 共线性与变量筛选 View (`/preprocessing/collinearity`)
* **Pearson 热力图**：输入变量间的相关系数矩阵。
* **VIF (方差膨胀因子) 诊断图**：VIF > 10 的严重共线性变量标红警告。
* **变量选择器**：提供智能剔除建议（如：“变量 $U_2$ 与 $U_1$ 相关度 0.98，建议剔除 $U_2$”），用户可勾选保留/剔除。

### 3.7 闭环寻优 View (`/modeling/optimization`)
* **Optuna 收敛曲线**：横轴为 Trial 序号，纵轴为验证集 FIT/RMSE 指标。
* **超参重要性柱图**：分析清洗窗长、动态阈值、时滞步数对最终模型 FIT 的贡献度。
* **Trial 明细表**：点击特定 Trial 可查看其对应的完整预处理参数与 ARX 估计参数。

### 3.8 Agent 智能工作台 (`/copilot`)
* **对话与计划区域**：支持自然语言输入，展示 LLM 生成的步骤计划 (Plan)。
* **DAG 视图**：节点实时反映工具调用状态（等待、运行中、完成、失败）。
* **HITL 确认点 (Human-in-the-Loop)**：在重大数据修改步骤弹出一键确认面板（包含参数、预计影响与依据）。
