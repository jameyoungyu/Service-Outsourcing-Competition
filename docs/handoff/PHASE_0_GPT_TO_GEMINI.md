## 3. 冻结的产品角色

### 3.1 建模工程师（主角色）

目标：用最少人工试错获得可用于系统辨识的高质量数据和可信模型证据。  
需要：看见数据问题、每一步参数、算法证据、版本变化、验证指标和失败原因。

### 3.2 评审/观察者（只读，P1）

目标：快速理解“Agent 做了什么、指标为什么变好、结果是否可追溯”。  
需要：演示路径、运行时间线、对比图、数据血缘和报告。

### 3.3 系统管理员（P1）

只配置 LLM、文件限制、存储与清理策略。MVP 不设计复杂权限。

**重要决定**：MVP 不依赖登录，阶段 0 不需要设计完整登录页。核心演示从工作台或数据集页开始。

## 6. 页面状态矩阵

每个异步页面必须设计：

| 状态 | 必须表现 |
|---|---|
| 初始空状态 | 用户可以执行的下一步，不显示伪数据图 |
| 上传中 | 文件名、大小、进度、取消 |
| 解析中 | 当前阶段和预计行为，不伪造百分比 |
| 配置错误 | 具体列、具体原因、修复入口 |
| 排队中 | 队列状态和创建时间 |
| 运行中 | 当前工具、步骤、耗时、可取消性 |
| 部分成功 | 已完成部分、失败部分、是否可继续 |
| 等待确认 | 影响范围、建议、证据、确认/拒绝 |
| 成功 | 结果摘要、版本 ID、下一步 |
| 失败 | 错误码、可读说明、重试与回退入口 |
| 已取消 | 保留的稳定产物和恢复方式 |
| 数据过多 | 后端下采样提示，不在前端静默截断 |

## 7. 图表规划

| 场景 | 推荐图表 | 必备信息 |
|---|---|---|
| 原始数据 | 多变量时序折线 | 单位、图例、缩放、采样说明 |
| 质量诊断 | 缺失率条形、采样间隔直方图、缺失热图 | 时间范围与问题阈值 |
| 清洗 | 清洗前后叠加、异常点散点 | 原值/处理值/处理原因 |
| 动态区间 | 时序背景高亮 + 区间排名 | 总分与分项、选中比例 |
| 时滞 | lag-correlation 曲线 + 候选表 | 候选峰、最终时滞、验证指标 |
| 共线性 | 相关热力图、VIF 条形、变量关系图 | 阈值、建议、影响 |
| ARX | 实际 vs 预测、残差、残差 ACF、指标卡 | train/validation/test 标签 |
| 寻优 | 收敛曲线、Trial 表、参数重要性 | 成功/失败 Trial、最佳值 |
| Agent | DAG + 时间线 | 工具、参数、输入、输出、理由 |
| 血缘 | 版本 DAG | 父版本、算法、参数、状态 |
| 报告 | 章节导航和图表目录 | 生成来源和可追溯 ID |

## 8. 工业软件设计原则

- 专业、克制、高信息密度；
- 以白色、浅灰和深色文字为主，单一强调色；
- 不使用大面积渐变、发光、过度玻璃拟态；
- 关键数值优先显示单位和所属数据分区；
- 危险操作使用清晰的影响说明，不只弹出“是否确认”；
- 长任务状态优先显示真实步骤和耗时，而不是装饰动画；
- 图表必须有坐标轴、单位、图例、阈值和数据来源；
- 空数据时不绘制零值占位图；
- 评委演示模式可提供固定导航顺序，但数据必须来自真实运行。
