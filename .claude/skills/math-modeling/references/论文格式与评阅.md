依据《全国大学生数学建模竞赛论文格式规范》（2025 年修订稿）。

下面标注了容易变动的条目。

## 一、硬性格式规范

### 页面

- 白色 A4 纸，单面或双面打印均可；
- 上下左右各留至少 **2.5 厘米**页边距；
- 从左侧装订；
- **不能有页眉**（页眉是身份信息泄漏的高发区）。

### 页序（纸质版）

| 页 | 内容 |
|---|---|
| 第 1 页 | 承诺书 |
| 第 2 页 | 编号专用页 |
| 第 3 页 | 摘要专用页 |
| 第 4 页起 | 正文 |
| 正文之后 | 附录 |

- **摘要（含标题和关键词）不超过一页**，无需翻译成英文；
- **页码从摘要页开始**，位于页脚中部，阿拉伯数字从 "1" 连续编号；
- **正文不要目录**；
- 正文尽量控制在 **20 页以内**；
- 附录页数不限，但必须打印并与正文装订在一起。

### 电子版

- 内容与格式（含附录）必须与纸质版**完全一致**；
- 必须是**单独一个文件**，PDF 或 Word 格式（建议 PDF）；
- 文件大小 **不超过 20MB**，不要压缩；
- **电子版不含承诺书和编号专用页**——电子版第一页必须是摘要页。

> 文件命名规则由各赛区规定，每年可能不同，以本赛区通知为准。

## 二、会被取消资格的事

这一节和扣分无关，是资格问题。

1. **正文或附录中出现任何可能显示答题人身份的标志**——校名、院系名、
   姓名、学号、指导教师名、队号（编号专用页除外）、
   带学校名的图片水印、代码注释里的路径含用户名、Excel 文件属性里的作者名。
   写完务必全文搜一遍这些词。
2. **附录缺少必要源程序，或程序不能运行，或运行结果与论文不符**。
   规范原文明确写了这三种情况"都可能会被取消评奖资格"。
3. **抄袭**，包括引用他人成果或公开资料而不按规定引用标注。
4. 在竞赛期间与队外人员讨论。

第 2 条是这个技能反复强调"先算再写"的直接原因：编造的数字不只是扣分，
它让附录代码和正文对不上，直接落入取消资格的判定条件。

## 三、论文结构

正文推荐结构（`assets/论文模板.md` 是可直接复制的骨架）：

```
一、问题重述
    1.1 问题背景
    1.2 问题提出            ← 逐条列出题目要求，与后文小节一一对应
二、问题分析
    2.1 问题一的分析
    2.2 问题二的分析
    ...                     ← 讲思路，不讲模型细节
三、模型假设
四、符号说明
五、问题一模型的建立与求解
    5.1 模型的建立
    5.2 模型的求解
    5.3 结果分析与检验
六、问题二模型的建立与求解
    ...
N、灵敏度分析
N+1、模型的评价与推广
    N+1.1 模型的优点
    N+1.2 模型的缺点
    N+1.3 模型的推广
参考文献
附录
```

**结构的要点：**

- "问题分析"和"模型建立"要分开。问题分析讲的是**为什么选这条路**，
  模型建立讲的是**这条路怎么走**。合在一起写，读者跟不上；
- 每问的"结果分析与检验"不能省。给出数值结果而不解释它意味着什么，
  等于把解释工作丢给评委；
- 灵敏度分析可以放在各问内部，也可以独立成章。**问题之间参数不共享时放各问内部
  更清楚，共享时独立成章更好**；
- "模型的推广"不要写成套话。有意义的推广是"本文的框架换掉 XX 假设后
  可用于 YY 场景"，而不是"本模型具有广泛的应用前景"。

## 四、摘要怎么写

摘要页是评委看的第一页，初评阶段常常也是唯一看完的一页。

### 结构

```
标题（居中）

摘要

[开篇一句：本文研究的问题是什么]

[问题一段落]
[问题二段落]
[问题三段落]
...
[可选：创新点或方法特色一句]

关键词：词1  词2  词3  词4
```

### 每段的写法

固定四段式：**针对什么 → 建立什么模型 → 用什么方法求解 → 得到什么具体结果**。

每段**必须有具体数字**。这是摘要好坏最容易检验的标准，也是评委的实际判据：
一份"泛泛而谈"的摘要，评分在平均分以下。

### 长度

- 全文（含标题、关键词）不超过一页；
- 中文一页大约 1000–1200 字（小四号、1.5 倍行距时更少）。
  留出余量，写到 900 字左右比较安全；
- 关键词 4–6 个，写**具体方法名和具体对象**（"混合整数规划""NSGA-II""产能分配"），
  不写"数学模型""优化""分析"这类没有区分度的词。

### 检验摘要的三个问题

写完自问：

1. 只读摘要，读者知不知道每一问的**答案是什么**（具体到数字）？
2. 只读摘要，读者知不知道你**用了什么方法**（具体到方法名）？
3. 有没有哪句话换到任何一篇别的论文里也成立？有的话删掉。

## 五、图表规范

- **图题在图下方，表题在表上方**，这是学术惯例，写反了显得不专业；
- 图表统一编号：图 1、图 2……表 1、表 2……，正文必须有引用
  （"如图 3 所示"），不引用的图表要么删要么挪附录；
- 坐标轴要有**名称和单位**；
- 中文图必须显示中文，别出现方块乱码——用 `scripts/setup_cn_plot.py`；
- 配色在全文保持一致；避免只靠颜色区分（黑白打印会失效），
  同时用线型或标记区分；
- 大表（超过半页）挪到附录，正文放摘要版；
- **图要能自解释**：光看图和图题，不看正文，读者应该知道这张图在说什么。

## 六、参考文献格式

按正文中的**引用次序**编号列出。正文引用处用方括号标注编号，如 `[1]`、`[1][3]`；
**引用书籍还必须指出页码**。

格式：

```
书籍：   [编号] 作者，书名，出版地：出版社，出版年。
期刊：   [编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。
网络资源：[编号] 作者，资源标题，网址，访问时间（年月日）。
```

示例：

```
[1] 姜启源，谢金星，叶俊，数学模型（第五版），北京：高等教育出版社，2018，第 112-115 页。
[2] 张三，李四，基于混合整数规划的产能分配方法，管理科学学报，25(3): 45-58，2022。
[3] 国家统计局，2024 年国民经济和社会发展统计公报，http://www.stats.gov.cn/xxxx，2025 年 3 月 1 日。
```

**两个自查**：

1. 参考文献列表里的每一条，正文里都有对应的 `[n]` 引用；
2. 正文里的每个 `[n]`，列表里都有对应条目。

`scripts/check_paper.py` 会自动核对这两条。

## 七、附录

附录内容应包括：

- **支撑材料的文件列表**（说明每个文件是什么、对应论文哪一部分）；
- **建模所用到的全部完整、可运行的源程序代码**，包括 Excel、SPSS 等软件的交互命令；
- 大表格、中间结果、详细推导。

**关键要求：代码必须完整且可运行，运行结果必须与论文一致。**
不满足会被取消评奖资格。

实践建议：

- 每段代码前用注释写明"对应论文第 X 节，生成图 Y / 表 Z"，
  让评委能对上号；
- 附录代码要包含数据读取路径的说明，不能依赖只有你机器上才有的绝对路径；
- 提交前在一台干净环境上从头跑一遍，确认能复现论文里的数字。

## 八、评阅要点

官方评阅要点强调的几件事，按实际权重排：

| 要点 | 落实到论文哪里 |
|---|---|
| **摘要** | 摘要页。评委首先看，权重高得不成比例 |
| **模型和算法是关键** | 模型建立与求解各节。模型是否对路、算法是否合适 |
| **假设的合理性** | 模型假设节。假设要承重、要有理由 |
| **建模的创新性** | 有独立小节点名，摘要里提及 |
| **结果的正确性** | 结果分析与检验节。有没有独立验证 |
| **文字表述的清晰性** | 全文。图表规范、符号统一、逻辑连贯 |

评分为百分制，一位评阅人给出的总平均分通常在 60 分附近——
意味着大部分论文集中在中间，**拉开差距的是摘要质量、检验的扎实程度、
和表述的清晰度**，而不是模型的花哨程度。

## 九、语言与表述

- **用陈述句写你做了什么，不用形容词夸自己做得好。**
  "本文建立的模型具有很强的实用性"是空话；
  "本模型在 200 组测试实例上平均求解时间 0.8 秒，最大偏差 2.1%"是内容。
  后者读者自己会得出"实用"的结论；
- 避免"较好""较优""合理""有效"这类无法检验的词单独出现——
  要用就跟上具体数字；
- 符号全文统一。同一个量不要一会儿写 $x$ 一会儿写 $X_i$；
- 公式要编号（右对齐），正文引用公式用编号；
- 第一次出现的缩写要给全称；
- 段落不要过长，一段讲一件事。
